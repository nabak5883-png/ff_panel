FF PANEL - Firebase Demo

FILES
- index.html
- style.css
- app.js
- firestore.rules

SETUP
1. Firebase Authentication: enable Email/Password.
2. Firestore Database: create the database.
3. Replace/keep the Firebase config in app.js as provided for your project.
4. Paste firestore.rules into Firestore > Rules and publish.
5. Register one account.
6. In Firestore, open users/{that-user-uid} and change ONLY role from "user" to "admin".
7. Login again. The Admin Panel will appear.

FEATURES
- Login
- Registration
- User profile
- Coins / Points / Matches / Wins display
- Tournament list
- Join tournament
- Admin create/edit/delete tournament

NOTE
This is a demo web app. It does not connect to or modify Free Fire/Garena game data, diamonds, accounts, or gameplay.
